# Build Omarchy Apps v0.2.1

Packaging and lifecycle guidance updated from the Task Manager for Omarchy edge submission.

- Match the current Omarchy-owned recipe model: AUR is an import source, while checked-in recipes and patches remain repository-owned.
- Choose edge-only testing, the normal edge → rc → stable pipeline or the fast release ring deliberately.
- Track source publication, package CI, merge, channel publication and device acceptance as separate states.
- Follow official package failures on the current PR head and keep published source archives immutable when backporting fixes.
- Test worker shutdown while idle, in flight and stopped; disconnect callbacks before teardown and use bounded unattended tests.

All ten canonical skills and OpenAI copies remain portable and model-agnostic. The new behavioral cases are documented but have not been independently executed. No package publication or live Omarchy acceptance is claimed by this bundle release.
