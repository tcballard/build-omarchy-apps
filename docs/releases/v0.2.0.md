# Build Omarchy Apps v0.2.0

Practical architecture guidance drawn from OmaCut and the Arcade refactor.

- Define startup, session, core, UI and adapter responsibilities with clear dependency direction.
- Generate an ARCHITECTURE.md worksheet with state ownership and lifecycle decisions.
- Cover worker cancellation, stale results, child cleanup and save-lock ordering.
- Expand focus/drag, theme replacement, portal failure and output-preservation test guidance.
- Keep all ten skills portable and model-agnostic, with synchronized OpenAI copies. Rust remains the default; existing stacks are preserved.

Includes portable, Claude, OpenAI plugin, OpenAI skills and complete source archives, plus SHA256SUMS, source/release manifests and an SPDX SBOM.

Development preview: bundle checks validate packaging and the scaffold helper. New agent behavioral cases are documented but not independently executed. No live Omarchy compatibility or agent-directory acceptance is claimed.
